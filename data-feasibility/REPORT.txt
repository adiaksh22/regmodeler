RegModeler data feasibility review
Checks performed October 12, 2026 (America/Los_Angeles).

DECISION
GO for a scoped MVP: authenticated FAA data access is now demonstrated in
addition to the public-source checks below. The user ran api-key-probe.cjs with
their key locally; the key was not provided in chat or saved by the probe.
This establishes data-access feasibility, not complete coverage or long-term
service reliability.

AUTHENTICATED API RESULTS (October 12, 2026)
All three document-type metadata requests and their sample file downloads
returned HTTP 200.
- TCDSMODEL: retrieved 1,500 distinct document records across two 750-record
  pages. The API reported 8,101 total records in this document type.
- STC: retrieved 1,500 distinct document records across two 750-record pages.
  The API reported 83,407 total records in this document type.
- ADFREAD (Emergency ADs): retrieved all 291 records reported by this response.
The two-page TCDS and STC samples contain no duplicate documentGuid values within
or across their pages. Totals are document records, not unique aircraft or
unique certificates; historical entries may be included.
The downloaded files have PDF signatures and parse successfully:
- TCDS sample: 42 pages, 105,359 extracted text characters.
- STC sample: 6 pages, 16,917 extracted text characters.
- Emergency AD sample: 4 pages, 9,039 extracted text characters.
Last-modified filtering returned HTTP 200 with zero records when queried after
the newest retrieved timestamp. This is consistent with no newer records. A
positive-result incremental query and repeated polling remain to be tested.
Evidence: evidence/api-key-probe-results.json and evidence/api-*.json/bin/txt.

DRS ACCESS FINDINGS
Plain HTTP requests to public UI metadata endpoints returned 403. The normal
guest browser flow returned 200 for document metadata, history, and complete
PDF downloads. No sign-in, API key request, or identity submission was performed.
Browser retrieval demonstrates availability; it is not the preferred production
integration and does not establish continuous-service reliability.

Downloaded the official 14-page DRS API Technical Design Document, version 6.0
dated August 7, 2025, and the document-type metadata mapping workbook.
Guide origin: https://drs.faa.gov/api/content/alf/672a7d0c-e369-4963-a2a5-63ed2772ac1d
Key request: https://drs.faa.gov/drs-api
Documentation: https://drs.faa.gov/help (DRS API section)

DOCUMENTED SUPPORTED API
GET https://drs.faa.gov/api/drs/data-pull/<doctypeName>
GET https://drs.faa.gov/api/drs/data-pull/download/<id>
GET https://drs.faa.gov/api/drs/data-pull/get-other-attachment-details/<id>
POST https://drs.faa.gov/api/drs/data-pull/<doctypeName>/filtered
Authentication: x-api-key header.
Metadata retrieval supports offset pagination (up to 750 documents per call),
docLastModifiedDate, and docLastModifiedDateSortOrder.
Mapping workbook identifies TCDSMODEL for TCDSs, STC for supplemental type
certificates, CAR for Civil Air Regulations, and ADFREAD for emergency ADs.
The metadata response documents file download URLs and last-modified dates.

LIMITS
These are point-in-time feasibility checks, not uptime or completeness guarantees.
Authenticated DRS API calls succeeded for the samples described above.
The full STC/TCDS catalogs have not been downloaded or audited.
Exact historical CAR/amendment text referenced by the sampled TCDSs has not been
fully retrieved. GovInfo annual editions alone do not reconstruct every amendment.
OEM service bulletins, manuals, and installation data may not all be publicly
available; do not promise their complete inclusion.
Source terms, operational request limits, and production-host access still need
verification before unattended public ingestion.
